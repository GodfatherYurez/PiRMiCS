# Конфигурация эксперимента ПР3

Клиент отправляет 50 надёжных `SHOOT` с интервалом 200 мс, `maxAttempts=5`, сервер слушает `127.0.0.1:7777`. Seed фиксирован для повторения потерь и задержек. В сервере вероятность потери применяется независимо к каждому входящему и исходящему UDP-пакету. Задержка задаётся серверу и добавляется к PONG/ACK. Укажите версию ОС и .NET SDK из фактического запуска.

| Серия | lossRate | delayMs | jitterMinMs | jitterMaxMs | seed |
|---|---:|---:|---:|---:|---:|
| `baseline` | 0 | 0 | 0 | 0 | 20261004 |
| `loss_5` | 0.05 | 0 | 0 | 0 | 20261005 |
| `loss_10` | 0.10 | 0 | 0 | 0 | 20261006 |
| `loss_20` | 0.20 | 0 | 0 | 0 | 20261007 |
| `delay_100_loss_5` | 0.05 | 100 | 0 | 0 | 20261008 |
| `jitter_loss_10` | 0.10 | 0 | 50 | 150 | 20261009 |

Для каждой строки запустите сервер:

```powershell
dotnet run --project PR3/Server -- 7777 <lossRate> <delayMs> <jitterMinMs> <jitterMaxMs> <seed>
```

Затем, во втором терминале:

```powershell
dotnet run --project PR3/Client -- 127.0.0.1 7777 <experiment_id> 50 200 5 PR3/docs/reliability_samples.csv
```

CSV включает число попыток, доставку с первой попытки, failed, время до ACK и RTO после каждого сообщения. Он содержит только фактические прогоны; пустой файл-шаблон не является результатом эксперимента.
