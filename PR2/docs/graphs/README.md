# Графики

Каталог предназначен для графиков, построенных по `latency_samples.csv` после выполнения всех серий по `Experiment_Config.md`.

Минимальный набор:

1. Линейный график RTT по номеру sample; timeout показывается как пропуск или отдельная отметка.
2. Столбчатая диаграмма `mean RTT`, `SRTT` и `loss rate` по сериям.
3. Histogram или box plot распределений RTT для `baseline`, `jitter` и `combined`.

Команды клиента уже формируют машинно читаемый CSV с разделителем `;`, поэтому эти графики можно воспроизводимо построить в Excel, LibreOffice или matplotlib без изменения исходников.
