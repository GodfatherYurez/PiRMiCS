# Спецификация ПР2

Один UDP-дейтаграмм содержит один пакет. Числа передаются в `big-endian`. В ПР2 сохранён `Magic = 0x4D50` из ПР1 для защиты от случайного мусора, поэтому заголовок занимает 9 байт.

| Смещение | Размер | Поле |
|---:|---:|---|
| 0 | 2 | Magic |
| 2 | 1 | packetType |
| 3 | 2 | sequenceNumber |
| 5 | 2 | payloadSize |
| 7 | 2 | protocolVersion |

`PING` имеет payload `clientSendTimeUs` (8 байт). `PONG` имеет исходную метку клиента, `serverReceiveTimeUs` и `serverSendTimeUs` (24 байта). RTT вычисляется только по клиентским монотонным часам.

До чтения payload проверяются размер заголовка, Magic, тип, версия, размер payload и границы буфера. Неверные пакеты отбрасываются без исключения наружу.
