# Проверка соответствия ПР1

Источник требований: «Практическая работа №1.pdf», страницы 1-3; исходный файл хранится у владельца в `../Pr1/`. Методичка не включена в публикуемый комплект.

## Реализовано

- язык C# и транспорт UDP;
- отдельные проекты протокола, сервера и клиента;
- заголовок пакета с `PacketType`, `SequenceNumber` типа `UInt16` и `PayloadSize`;
- команда `MOVEMENT` с координатами `x`, `y`, `z` типа `Float32`;
- команда `SHOOT` с полем `weaponId` типа `UInt8`;
- сериализация чисел в сетевом порядке байтов (`big-endian`);
- проверка magic, версии, типа, длины и содержимого пакета;
- журналирование полученных команд на сервере;
- хранение сервером авторитетного состояния игрока;
- ответ клиенту пакетом `STATE` после каждой корректной команды;
- отправка клиентом команды один раз в секунду и вывод ответа;
- описание выбранной архитектуры и схема обмена в `docs/Architecture_Design.md`;
- спецификация бинарного протокола в `docs/Protocol_Specification.md`;
- проверено 14.09.2026: `dotnet build PR1_UdpBasics.slnx -c Release`, SDK 10.0.401, целевая платформа net8.0; 0 ошибок, 0 предупреждений;
- проверено 14.09.2026: запуск собранных Server.dll и Client.dll на `127.0.0.1:7777`, получены STATE для seq=1..5; после двух MOVEMENT позиция `(1.0, -0.2, 0.5)`, после SHOOT `shots=1`. Проверка LAN и готовых EXE отдельно не выполнялась.

## Не требуется для базовой части

- CRC32 и аутентификация относятся к дополнительному заданию и не реализованы.
