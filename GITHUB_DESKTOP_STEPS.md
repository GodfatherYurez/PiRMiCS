# Работа с репозиторием в GitHub Desktop

Локальный проект уже подключён к `GodfatherYurez/PiRMiCS`. В репозитории ПР1 находится в корне, ПР2 — в `PR2/`, ПР3 — в `PR3/`. История Git сохраняет практики отдельными осмысленными коммитами.

## Продолжить текущую работу

1. В GitHub Desktop выбери репозиторий `PiRMiCS` и ветку `feature/pr2-integration`.
2. Проверь коммиты во вкладке **History**. Последний коммит ПР3: `feat(pr3): add reliable UDP delivery`.
3. Чтобы отправить ветку на GitHub, нажми **Publish branch**. Затем нажми **Create Pull Request** и открой PR в `main`.

Текущая ветка содержит ПР2 и ПР3 поверх `origin/main`. После ревью и слияния PR следующую практику начинай от обновлённой `main` в отдельной ветке, например `feature/pr4-client-prediction`.

## Коммиты следующих практик

- Храни файлы каждой практики в отдельном каталоге `PR4/`, `PR5/` и далее.
- Делай небольшие тематические коммиты, чтобы история показывала этапы работы.
- Используй понятные сообщения, например `feat(pr4): add client-side prediction` или `docs(pr4): describe validation results`.
- Отправляй ветку и открывай Pull Request в `main` после локальной сборки и проверок.

Методичка ПР1 упоминает GitVerse и ветку `feature/udp-echo`. Сейчас команда работает с GitHub и GitHub Desktop; если преподаватель требует конкретную площадку, согласуй это отдельно.
